# 核—风—储研究总路线

## 硬目标

- 正式论文题目保持《面向核-风-储耦合系统的压水堆柔性运行建模与协调控制研究》。
- 开题报告只读；老师提出的风电数据来源、作用和多时间尺度预测要求在实施目录中闭合。
- 现有44状态模型必须先通过G0；后续方法、图表和论文均在同一经验证模型上展开。
- 快速成果争取在2026-11-15前录用、2027-02-15前获得带ISBN或ISSN的正式出版物。

## 依赖关系

模型主链：`G0 → E2/E3 → E4 → E5 → E6 → E7/E8`。  
数据主链：`W0 → W1 → E2/E3/E4`，以及`W0 → W1 → W2 → W3 → E6/E7/E8`。

E2程序框架可与W0—W1并行，但大规模正式网格必须等待数据标定范围冻结。快速论文只使用W0—W1与E2子集；学位论文必须完成W2—W3。

## 时间止损

- 若2026-08-30前G0仍有关键动态问题，不使用未经验证结果赶会议，快速成果切换为中文期刊路线。
- 若W0无法恢复现有400 s轨迹来源，不删除旧轨迹；将其降为待审计算例并使用新数据链生成正式轨迹。
- 若风电预测未稳定优于持续性基线，不宣称预测算法先进，只报告数据标定与预测信息敏感性。
- 若非均匀预测时域在相同算力预算下没有稳定收益，将其降为计算折中，不作为独立创新。
- 若协调QP未扩大柔性域，只能在降低危险违规或执行器负担存在重复性收益时保留为贡献。
- 若会议无法书面确认ISBN和预计出版时间，不缴费、不投稿。
