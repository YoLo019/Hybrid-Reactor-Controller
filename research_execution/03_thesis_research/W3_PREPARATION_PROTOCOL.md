# W3非均匀预测时域准备协议

**状态：W3-P0 PASS / W3-C0 PASS / W3-S0 PASS / W3-V1 PENDING**  
**冻结版本：`w3_nonuniform_horizon_v1`**  
**日期：2026-08-23**

## 1. 研究问题

现有MPC使用30个0.5 s均匀节点，只覆盖15 s；W2预测误差证据覆盖10 min至6 h。W3检验：在不增加决策变量和预测跨度的条件下，把节点集中到控制近端、在预测不确定性增大的远端变粗，是否能比均匀节点更好地兼顾快速执行器响应、慢热工前瞻和在线求解成本。

W3本身不主张新的风电预测算法。实际预测基线沿用W2-F1冻结的`persistence`；ridge只作负比较，perfect foresight只作不可部署信息上界。

## 2. 数据驱动节点

- 基础控制更新：0.5 s；
- 总预测跨度：6 h，对齐W2最远360 min时域，且短于W1约22.67 h的`1/e`相关时间；
- 决策节点：30，与现有MPC变量数相同；
- 强制锚点：15 s现有MPC跨度，以及W2的10、20、30、60、120和360 min误差节点；
- 各段节点数：6、6、4、4、4、3、3。W2 persistence RMSE随时域单调增加，因此远端不增加节点密度；每段内部按0.5 s整数步均匀布点；
- 第一预测区间固定为一个0.5 s控制步，确保实际施加的首个控制量与基础控制周期一致。

机器节点由`../../4_4/flexibility/prepare_w3_horizon.py`生成，不允许根据后续闭环结果移动节点。

## 3. 公平均匀对照

均匀对照同样使用6 h跨度、30个阀门决策、同一44状态线性化对象、输出、权重、约束、求解器容差和0.5 s滚动更新。为保持首个实际控制动作的语义，首区间固定0.5 s，其余29个区间在剩余跨度内按整数基础步尽可能均分，记为`uniform_tail`。

该比较只改变预测节点位置。若未来比较改变变量数、跨度或求解预算，必须另列实验，不能并入W3主比较。

## 4. QP实现契约

每个可变区间内阀门命令保持常值。由基础离散模型`(A_d,B_d)`计算区间转移：

\[
A_i=A_d^{m_i},\qquad B_i=\sum_{j=0}^{m_i-1}A_d^jB_d,
\]

其中`m_i`为该区间包含的0.5 s基础步数。跟踪、温度和控制幅值代价按区间长度做矩形积分权重；控制增量只在节点切换时计一次，速率上界按相邻决策间隔缩放。默认全1步区间必须恢复原均匀预测映射。

## 5. 执行门

1. `W3-P0`：验证W1/W2证据、节点锚点、相同跨度/变量预算、锁定数据未访问；
2. `W3-C0`：独立代码审查确认凝聚映射、代价权重、速率约束和预览采样没有阻塞错误；
3. `W3-S0`：在真实44状态工作点线性化上分别构造nonuniform与uniform-tail QP，各重复求解3次；两者使用同一发布时刻冻结的persistence provider，只验证结构、有限命令、冻结OSQP路径、无fallback和轻量预算；
4. `W3-V1`：资源允许后，在同预测信息和预注册场景上运行正式闭环对比；W3-S0不提供控制器性能主张。

E2运行期间只允许执行P0/C0/S0这类轻量步骤，不启动W3-V1正式闭环批量仿真。

## 6. 成功与失败解释

W3-P0要求所有证据与预算门通过。W3-S0要求两种QP均构造成功、求解状态可接受、三次均使用冻结OSQP且无fallback、命令有限、单控制器构造不超过20 s且平均求解不超过5 s。超过预算或长时域转移数值异常时，不缩短跨度或事后删除节点，应回到离散/缩放实现处理。

实际预测路径必须由`forecast_type`和发布时刻provider显式提供；`persistence`或ridge缺少provider时直接拒绝。只有显式标记`perfect_foresight`的路径可以调用未来目标函数。nonuniform与uniform-tail必须共享同一issue-time信息集，再分别在各自节点末端采样。

正式W3只有在相同预测信息和算力预算下报告离散误差、求解时间、超时率、闭环跟踪、频率、温度、阀门、棒速、BESS和SOC指标后，才能判断非均匀时域是否有效。
